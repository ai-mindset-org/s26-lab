# garden — четыре навыка с сессии «vibe-coding и context engineering» (W3, 24.08)

Плагин Стаса Федосеева для Claude Code и Codex. Код и инструкции живут в отдельном репозитории —
так навыки ставятся одной командой:

```
claude plugin marketplace add fedoseevstanislav/garden
claude plugin install garden@garden
```

(в сессии — те же команды через `/plugin ...`; для Codex — склонировать репозиторий и скопировать `skills/*` в свою папку навыков)

## Что внутри

| навык | что делает |
|---|---|
| `/garden:profile` | опросник 40 пунктов (IPIP-NEO, рус.) → профиль продуктивности: какие методы планирования приживутся, какие нет; опциональный аудит уже построенной системы |
| `/garden:play` | интервью «что для вас игра»: 5 вопросов → файл `игра.md` |
| `/garden:mini-tz` | интервью-сбор требований на одну автоматизацию → `мини-тз.md` с критериями «да/нет» и запретами |
| `/garden:review-loop` | петля проверки: работу принимает ревьюер на другой модели, по критериям из мини-ТЗ, вердиктами ПРОШЁЛ / НЕ ПРОШЁЛ / НЕ МОГУ ПРОВЕРИТЬ — до ПРИНЯТО |

Цикл: `/garden:mini-tz` → сборка → `/garden:review-loop`.

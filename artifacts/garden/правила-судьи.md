# Правила судьи — проверка, которая читает результат вместо вас

Ядро петли проверки, в любом инструменте:

- судья — **новая сессия**, лучше другая модель, ещё лучше другое семейство:
  самопроверка в той же сессии не отказывает;
- критерии — **бинарные**, по одному за раз, из мини-ТЗ, а не из головы судьи;
- на каждый критерий — **свидетельство** (цитата, файл, факт запуска), потом вердикт:
  ПРОШЁЛ / НЕ ПРОШЁЛ / НЕ МОГУ ПРОВЕРИТЬ — третий исход обязателен,
  без него судья угадывает;
- судья **не чинит** и не улучшает формулировки — только режет;
- первой строкой ответа — итог: ПРИНЯТО / ДОРАБОТАТЬ / ОТКЛОНИТЬ;
  ПРИНЯТО = все обязательные критерии прошли и не нарушен ни один запрет;
- потолок раундов (обычно 3): не сошлось — остановиться и посмотреть
  на постановку и критерии, а не крутить дальше;
- проверка, которая ни разу не отказала, ещё не проверена.

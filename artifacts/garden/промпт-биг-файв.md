# Промпт: оцени меня по Big Five (для агента, который вас уже знает)

Вставьте своему агенту (Claude Code, Codex — любому, у кого есть ваш контекст):

```
Оцени меня по методологии Big Five — на основании всех наших диалогов
и всего, что ты обо мне знаешь.

Для каждой из пяти черт: балл (низкий / средний / высокий),
2–3 доказательства из моих файлов и сессий с датами,
и отдельно — чего тебе не хватает, чтобы оценить.

Не льсти: где данные противоречивы, скажи прямо.
В конце: какие методы планирования с таким профилем приживутся,
какие — нет, и почему.
```

Это зеркало, а не диагноз: агент покажет то, что вы готовы увидеть.

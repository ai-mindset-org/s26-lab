Правило приёмки одно на весь репозиторий: **черновик собирает кто угодно, принимает человек**. Подробности — [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md), визуальный язык схем — [`../../STYLE.md`](../../STYLE.md).

## формат

**markdown-шаблоны, которые каждый может забрать и адаптировать под себя.** это единственное требование к форме: файл должен работать, когда его скопировали в чужой vault и заполняют своим.

- один файл – одна вещь, самодостаточно;
- пустые места для заполнения оставляем видимыми;
- личное вычищаем, оставляем механику;
- строчные буквы, en-dash «–» – общий стиль репозитория, [`../../STYLE.md`](../../STYLE.md).

кладите сюда столько файлов, сколько нужно. навигацию соберём после.

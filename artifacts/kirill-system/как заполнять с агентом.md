# как заполнять с агентом

> **Что это за файл:** промпты, если заполняешь конституцию не в одиночку. Необязательный. Всё, что здесь есть, можно сделать руками — просто дольше.
> **Главное ограничение:** агент не знает, чего ты хочешь. Он умеет две вещи — задавать вопросы, которые ты сам себе не задашь, и вытаскивать закономерности из твоих собственных текстов. Формулировки после него всё равно переписывай своими словами: чужая формулировка не работает, даже если она точнее.
> **И честно про глубину:** качество разбора линейно зависит от объёма материала, который ты дал. На трёх абзацах о себе получится общее место. На годе переписки, заметок и рабочих логов — попадание.

## 1. интервью для Фундамента

Самый рабочий сценарий, если [01. фундамент](<01. фундамент.md>) не пишется. Не проси написать за тебя — проси спрашивать.

```
Ты берёшь у меня интервью, чтобы я смог написать документ
о том, как я хочу прожить свою жизнь и каким человеком быть.

Задавай по ОДНОМУ вопросу за раз и жди ответа.
Начни с простого и конкретного, не с «в чём смысл жизни».
Если я отвечаю общими словами — переспрашивай, проси пример
из последнего месяца.
Не хвали ответы и не подытоживай после каждого.

После 15–20 вопросов собери из моих ответов черновик по разделам:
максима, миссия, ценности, сильные стороны, что хочу развивать,
каким человеком хочу быть.

Используй мои слова, а не свои. Где я не сказал — оставь пустое место,
не додумывай.
```

## 2. вытащить принципы из своих текстов

Работает, когда ощущение «принципы у меня есть, но сформулировать не могу». Подойдут посты, рабочие переписки, старые заметки, дневник, история чатов с моделями.

```
Вот мои тексты за последний год: [материал].

Найди правила, по которым я на самом деле живу и работаю — не те,
которые я декларирую, а те, которые видны из поступков и решений.

Для каждого правила приведи 2–3 цитаты, из которых ты его вывел.
Отдельно назови места, где декларируемое и фактическое расходятся.
Не смягчай.
```

## 3. три паттерна, которые мешают

Это разбор для [07. слабые стороны и ошибки](<07. слабые стороны и ошибки.md>). Даёт результат только на большом корпусе: год переписок, список проектов, незакрытые задачи, черновики.

```
Вот материал обо мне: [проекты, задачи, переписка, заметки].

Найди 3 повторяющихся паттерна, которые мешают мне делать то,
что я решил. Не разовые ошибки — механизмы, повторяющиеся
на разных проектах.

Для каждого:
— название, которое я узнаю
— конкретные проявления с датами и именами проектов
— 3–4 гипотезы, почему так, включая неприятные
— что делать
— критерий самообмана: по какому признаку я пойму, что применяю
  не решение, а очередной способ не делать

Не подбадривай. Не смягчай. Если материала не хватает
на честный вывод — скажи об этом, а не выдумывай.
```

Последний абзац обязателен. Без него модель по умолчанию выдаёт складную и приятную версию, а от складной версии ничего не меняется.

## 4. ревизия при перечитывании

Раз в две недели, когда лень перечитывать всё самому.

```
Вот моя конституция: [файлы].

Найди:
— проекты со статусом «В работе», у которых поле «Обновлено»
  старше двух месяцев
— цели из Фундамента, которые не обслуживает ни один проект
— проекты, которые не обслуживают ни одной цели
— правила, не отмеченные третье перечитывание подряд
— области, где поле «Текущее» не менялось полгода

Просто список расхождений. Без советов.
```

## 5. оппонент

Раз в год, на глубоком пересмотре.

```
Вот моя конституция: [файлы].

Сыграй оппонента. Найди места, где я вру себе: где красивая
формулировка прикрывает то, что я просто не хочу этого делать.
Где цель написана так, что её невозможно провалить.
Где ценность заявлена, но за год не было ни одного действия по ней.

Приводи доказательства из текста. Одно возражение — одна цитата.
```

## чего не стоит делать

**Просить написать конституцию за себя.** Получится гладкий текст про абстрактного хорошего человека. Перечитывать его будет незачем — а вся ценность системы в перечитывании.

**Отдавать агенту поле «Следующее действие».** Он придумает правдоподобное. Следующее действие — это то, что ты реально сделаешь завтра, и знаешь это только ты.

**Держать конституцию в чате.** Она должна лежать файлами, которые открываются без интернета и переживут смену модели, подписки и компании. Агент — гость в этой папке, а не её владелец.

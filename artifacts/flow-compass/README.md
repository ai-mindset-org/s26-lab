# Flow Compass 🧭

Плагин лаборатории **AI Mindset S26 {flow}**. Помогает разобраться, что такое продуктивность лично для тебя, — и потом каждую неделю лабы проверять, что агентный стек делает жизнь легче, а не сложнее.

Инструментов всё больше, а легче не становится. Часто потому, что мы оптимизируем «больше сделать», не спросив «зачем» — и ускоряем чужое определение продуктивности.

## Как это работает

**Стартовая сессия (~60 минут):**
1. **Диагностика** — короткое интервью: как тебе органично думать о ценностях, что болит, на развилке ли ты.
2. **Подбор фреймворка** — не один протокол для всех, а тот способ, который подходит тебе. В основе — верифицированный рисёрч:
   - **Card Sort** (UNM) — выбирать ценности из готового, а не формулировать из головы
   - **ACT / VLQ** — ценности как направление действия; 10 доменов, важность × реальные действия
   - **Шварц** — карта 10 базовых ценностей и их структурных конфликтов (реплицировано в 80+ странах)
   - **Odyssey Plans** (Stanford DYL) — три версии пяти лет, для тех, кто на развилке
   - **PERMA + CHI-аудит** — против навязанной продуктивности: 6 измерений личной продуктивности из дневникового исследования knowledge workers (CHI 2019)
   - **Колесо баланса** — наполненность × внимание по 8 сферам, поиск разрывов
3. **Твоё определение продуктивности** — одна фраза твоими словами, с проверкой на «своё или навязанное» (SDT).

**Каждую неделю лабы** — чекин (~10 минут): оценка недели по *твоему* определению, динамика метрик твоего фреймворка и **ИИ-аудит**: каждая автоматизация проверяется вопросами «вернула ли внимание или добавила обслуживания», «ускоряет ли она то, что тебе важно», «инструмент служит тебе — или ты уже обслуживаешь инструмент». Выключить лишнего агента — легитимный результат.

**В конце лабы** — обзор: динамика по неделям и главный ответ — какие автоматизации сделали жизнь легче, а какие сложнее.

Артефакты: `flow-compass-результат.md` (компас) и `flow-compass-журнал.md` (динамика).

## Установка

В Claude Code выполни:

```
/plugin marketplace add Voronik1801/flow-compass-plugin
/plugin install flow-compass
```

Либо без установки — запусти Claude Code с плагином напрямую. Из этого репозитория:

```bash
git clone https://github.com/ai-mindset-org/s26-lab
claude --plugin-dir ./s26-lab/artifacts/flow-compass
```

Либо из отдельного репозитория плагина:

```bash
git clone https://github.com/Voronik1801/flow-compass-plugin
claude --plugin-dir ./flow-compass-plugin
```

## Команды

- `/flow-compass:start` — стартовая сессия
- `/flow-compass:checkin` — еженедельный чекин
- `/flow-compass:review` — финальный обзор лабы
- `/flow-compass:resume` — продолжить с того места, где остановились

Лучше проходить в отдельной пустой папке — там будут жить твои артефакты.

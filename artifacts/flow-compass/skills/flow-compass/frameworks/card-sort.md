# Card Sort — сортировка ценностей

**Когда подходит:** человеку трудно назвать ценности словами «из головы», но легко узнать своё в готовом списке. Формат «выбирать, а не формулировать».
**Основа:** Personal Values Card Sort (Miller et al., UNM), адаптация под диалог. Первоисточник: https://casaa.unm.edu/assets/inst/personal-values-card-sort-2.pdf

## Ход в диалоге (~25 минут)

1. Объясни правила: «Покажу список ценностей. Твоя задача — быстро, не раздумывая, разложить на три стопки: очень важно / важно / не моё. Первая реакция честнее обдуманной.»
2. Покажи список порциями по ~10, человек называет только «очень важно» (остальное — важно/не моё по умолчанию). Список из 40:

   Принятие · Точность · Достижения · Приключения · Красота · Забота о других · Вызов · Комфорт · Сообщество · Сострадание · Творчество · Надёжность · Семья · Дружба · Рост · Здоровье · Честность · Юмор · Независимость · Внутренний покой · Близость · Знание · Мастерство · Осознанность · Умеренность · Новизна · Порядок · Страсть · Популярность · Власть · Цель/смысл · Рациональность · Ответственность · Риск · Безопасность · Самопознание · Служение · Простота · Традиция · Свобода

   Плюс всегда: «есть что-то важное, чего в списке нет? Добавь своими словами» (в оригинале — пустые карточки).
3. Из стопки «очень важно» → попроси выбрать **топ-10**, потом сузить до **топ-3**. Сужение — самая ценная часть: проговаривай вслух, от чего человек отказывается и почему.
4. По каждой из топ-3 — один вопрос: «где эта ценность проявилась в твоей жизни за последний месяц? А где ты её предал(а)?»

## В артефакт

Топ-3 с формулировкой «почему» словами человека; топ-10 списком; добавленные вручную ценности пометить — они самые личные.

## Частая связка

После card sort — экспресс-VLQ по топ-3: «важность у всех трёх высокая, а сколько реальных действий за 2 недели?» Разрыв → материал для фазы 4.

## Для чекинов

По каждой из топ-3 ценностей — одна оценка 1–10: «насколько твои действия на этой неделе соответствовали этой ценности?» (+ один пример-подтверждение). Динамика соответствия — метрика прогресса; стабильно низкая оценка при высокой важности — повод обсудить барьер.

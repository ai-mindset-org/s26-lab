# Repository instructions

## Public repository links

For organization-owned copies, follow the [public repository standard](https://github.com/ai-mindset-org/.github/blob/main/PUBLIC_REPOSITORIES.md). Keep the managed labs/knowledge block near the beginning of README; preserve readable labels and existing registered attribution. The `Public repository links` CI check uses the shared read-only policy. Update `.github/public-links.json` together with approved About fields; do not weaken a failing check or replace a tool demo with a generic homepage.

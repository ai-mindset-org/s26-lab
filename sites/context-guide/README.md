# sites/context-guide

одностраничная сборка гайда из `guide/*.md` для деплоя. исходник правится **только в `guide/`** — эта папка производная и пересобирается целиком.

## пересборка

```bash
python3 sites/context-guide/build.py
```

Собирает `index.html` (~116 КБ) и копирует одиннадцать картинок в `assets/` рядом. Зависимость одна — `markdown` (python).

Что делает сборщик, кроме склейки:

- срезает первый `# заголовок` каждого раздела — он рисуется шапкой секции
- переписывает ссылки между разделами `03-layers.md` → `#s03`, то есть навигация внутри страницы
- `../assets/` → `assets/`, картинки кладутся рядом со страницей, чтобы папку можно было выкладывать как есть
- ссылки на `CONTRIBUTING.md` и корневой README ведут на github

## что внутри страницы

шапка · липкая навигация чипами · интро и карта разделов · десять секций подряд с якорями `#s01`…`#s10` · подвал с авторами.

## отклонение от `shaper.css`

в `shaper.css` на `body` стоит `text-transform: lowercase`. для фигур это верно, для длинного текста — нет: строчные съедают имена авторов и названия («Obsidian», «AI Mindset», «Александр Поваляев»). на странице lowercase применяется только к микро-подписям, тело текста идёт как написано в исходнике. остальные токены — цвета, шрифт, рамка 1px, инверсия, жёлтая точка — взяты без изменений.

## перед деплоем — про размер

`index.html` = 116 КБ, под gzip **30 КБ**. отдавать со сжатием обязательно: на нашем канале уже ловили обрыв больших ответов — `content-length` 147904 доходило 20241 байтом, битый файл, пустая страница в браузере. под gzip тот же материал проходит.

приёмка не по коду ответа, а по факту: сравнить `size_download` с `content-length` и открыть страницу глазами.

```bash
curl -s -o /dev/null -w "%{http_code} %{size_download} / %{size_request}\n" -H "Accept-Encoding: gzip" https://<host>/
```
